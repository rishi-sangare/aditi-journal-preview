# Aditi Mishra · journal preview

A playable prototype of Aditi Mishra's portfolio: a crumpled-note intro that becomes a ring-bound journal on a desk.

This is a preview for feedback, not the final site. Photos, the handwriting font, her reflections and the contact form are placeholders.

Live preview: https://rishi-sangare.github.io/aditi-journal-preview/
